🔐 Configurar Login Google

Guia passo-a-passo para ativar Google OAuth no StudioMaker

1

Adicionar Variáveis de Ambiente no Vercel

Objetivo: Configurar as credenciais do Supabase no Vercel para que o app saiba qual banco de dados usar.

  1. Acesse o Vercel Dashboard: vercel.com/dashboard
  2. Encontre o projeto studio-maker3d
  3. Clique em Settings (engrenagem no topo)
  4. Na barra lateral esquerda, clique em Environment Variables

Adicionar cada variável:

Nome da Variável Valor Onde Copiar
NEXT_PUBLIC_SUPABASE_URL https://dgcdltcpvnultwduypcu.supabase.co Já conhecida
NEXT_PUBLIC_SUPABASE_ANON_KEY eyJhbGc... (copie do Supabase) Supabase → Settings → API Keys
NEXT_PUBLIC_APP_URL https://studio-maker3d.vercel.app URL do seu site
NEXT_PUBLIC_SITE_URL https://studio-maker3d.vercel.app MESMA URL acima
SUPABASE_SERVICE_ROLE_KEY eyJhbGc... (copie do Supabase) Supabase → Settings → API Keys
⚠️ Importante: NEXT_PUBLIC_SITE_URL deve ser igual a NEXT_PUBLIC_APP_URL

Como adicionar:

  1. Clique no botão "Add New"
  2. Em "Name", cole o nome da variável
  3. Em "Value", cole o valor
  4. Clique "Save"
  5. Repita para cada variável
✓ Quando terminar: Você deve ver todas as 5 variáveis listadas
2

Redeploy no Vercel

Objetivo: Forçar o Vercel a reconstruir o app com as novas variáveis.

  1. No Vercel Dashboard, vá em Deployments
  2. Clique no deployment mais recente
  3. Clique no botão "Redeploy" (canto superior direito)
  4. Selecione "Use existing Build Cache"
  5. Clique "Redeploy" novamente
⏳ Aguarde: O deployment leva 1-2 minutos. Espere até ficar verde (Ready)
3

Configurar Callback URL no Supabase

Objetivo: Informar ao Google para redirecionar de volta para studio-maker3d.vercel.app após autenticação.

  1. Acesse app.supabase.com
  2. Selecione seu projeto makerflow
  3. Na barra lateral, vá em Authentication
  4. Clique em Providers
  5. Procure por Google
  6. Clique em Google para expandir

Adicionar URLs de Redirect:

Você verá um campo "Authorized redirect URIs" com:

https://dgcdltcpvnultwduypcu.supabase.co/auth/v1/callback

Você precisa ADICIONAR (não substituir):

https://studio-maker3d.vercel.app/auth/callback http://localhost:3000/auth/callback

Resultado final:

https://dgcdltcpvnultwduypcu.supabase.co/auth/v1/callback https://studio-maker3d.vercel.app/auth/callback http://localhost:3000/auth/callback
⚠️ Importante: Mantenha a primeira linha! Apenas ADICIONE as outras duas.
  1. Clique no campo "Authorized redirect URIs"
  2. Posicione no final da última linha
  3. Pressione Enter
  4. Cole: https://studio-maker3d.vercel.app/auth/callback
  5. Pressione Enter novamente
  6. Cole: http://localhost:3000/auth/callback
  7. Clique "Save"
✓ Quando terminar: As 3 URLs devem estar listadas
4

Testar Login Google

Objetivo: Verificar se tudo está funcionando.

  1. Aguarde o Vercel Redeploy terminar (fica verde)
  2. Acesse: https://studio-maker3d.vercel.app/login
  3. Clique em "Continuar com Google"
  4. Selecione sua conta Google
  5. Conceda permissão
✓ Sucesso! Se conseguir fazer login, está tudo funcionando!

📋 Checklist Final

  • Vercel: 5 variáveis de ambiente adicionadas
  • Vercel: Redeploy concluído (status: Ready)
  • Supabase: 3 URLs adicionadas em Google Providers
  • Teste: Login Google funcionando

Se tudo passou no checklist: Login Google está 100% funcional! 🎉
